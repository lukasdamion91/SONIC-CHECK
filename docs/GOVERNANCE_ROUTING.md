## Technical-enforcement boundary

Repository instructions and review templates route policy; they are not a
cryptographic or hosting permission barrier. This candidate does not alter
Render automatic deployment, GitHub protection, Cloudflare permissions,
credentials, scoring, catalogues, checkout or other sessions. Check actual
workflow and hosting effects before any specifically approved remote action.

Automatic hosting/release settings and account-level enforcement require an
actual configuration change with verified effects. Old running
jobs, external clones, other conversations and tools that do not load these
files cannot be claimed updated merely because a repository was changed.
Report those limits explicitly. No completed forensic certification, recovered
historical rights evidence, scanner improvement or full CI pass is implied.
